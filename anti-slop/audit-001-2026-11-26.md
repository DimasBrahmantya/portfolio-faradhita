# Antislop Audit — Portfolio Faradhita Eka Septiana v2 (FigCraft)

- **Tanggal**: 2026-11-26
- **Mode**: Mode 2 (AFTER)
- **Target**: `design/Faradhita_Portfolio_v2.figcraft` & `design/exports/*.png`
- **Design Read**: *Editorial Data Analyst & Data Science Portfolio + CMS Admin UI for recruiters, HRD, and academic reviewers, in a warm analytical editorial style anchored in crimson-burgundy and deep teal, dial ENERGY 2 / RHYTHM 3 / MOTION 1.*

## Daftar Temuan Bernomor

1. **[HIGH] [R-25]** Teks badge `Py` (`#FFD43B`) di atas latar `#3776AB` pada grup Keahlian memiliki rasio kontras `3.39:1` (gagal WCAG AA `4.5:1` untuk teks ukuran `12px`).
2. **[MEDIUM] [R-01 / R-31]** Kartu `Publikasi Jurnal Ilmiah` menggunakan garis tepi kiri tebal `5px` (`#A61D35`) yang menyerupai pola *colored left stripe* tanpa catatan pembeda semantik pada desain itu sendiri dibanding kartu lain.
3. **[LOW] [R-29]** Tujuh badge perangkat di Section 05 Keahlian memakai 7 warna merek terpisah (`#3776AB`, `#B85300`, `#176EA8`, `#1A56C4`, `#1D6F42`, `#185ABD`, `#B83814`) di luar palet inti `2-3 warna + 1 aksen`, meskipun merepresentasikan identitas logo tools pihak ketiga.
4. **[LOW] [R-34]** Mode Gelap baru dibuat lengkap untuk desktop (`1440px`), sedangkan frame responsif tablet (`768px`) dan mobile (`390px`) baru tersedia dalam varian Mode Terang.
5. **[HIGH] [R-35]** Deliverable berupa prototipe statis FigCraft (bukan aplikasi web Next.js berjalan), sehingga klik-uji interaktif dan Console check baru dapat dijalankan pada tahap implementasi Next.js (inspeksi kode/layer dan ekspor PNG sudah dilakukan).

## Catatan Rasional Desain (R-31)

- **Palet Warna (`#F6F3EE` / `#0E171E`, `#0B6168`, `#A61D35`)**: Mempertahankan identitas merah anggur dari foto kebaya Faradhita dan HTML awal sebagai aksen fokus tunggal (`#A61D35` / `#FF7A8E`), dipasangkan dengan teal analitis (`#0B6168` / `#58C9D1`) untuk angka, tag, dan focus ring di atas kanvas hangat `#F6F3EE` (mode terang) atau slate gelap `#0E171E` (mode gelap).
- **Tipografi (`Playfair Display` + `Source Sans 3` + `Liberation Mono`)**: Serif editorial untuk nama dan judul studi kasus, sans-serif netral untuk keterbacaan paragraf bahasa Indonesia & formulir CMS, serta monospace khusus metadata/indeks kecil `11-12px`.
- **Variasi Ritme (`RHYTHM 3`)**: Hero asimetris 60/40 dengan bingkai foto lengkung atas, Tentang Saya 2-kolom dengan kartu metadata, 3 proyek dengan komposisi berbeda (split berdampingan, brief + galeri 2 baris, dan split terbalik dengan 3 kartu segmen RFM), timeline bergaris vertikal + strip 3 foto dokumentasi magang, grid sertifikat 3x2, matriks keahlian 3 kelompok, dan pita kontak full-bleed gelap.
